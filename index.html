About & Help

This web version runs real object detection in your browser with TensorFlow.js and the COCO-SSD model (80 everyday classes, including person, cell phone, laptop, backpack, handbag, suitcase and bottle).

The JSON data file chooses which classes are watched and how they are grouped. It cannot teach the model new objects.

The full project (Streamlit, YOLO, OpenCV and MySQL) runs on your laptop with streamlit run main.py. This page is a lighter browser edition: the camera needs permission and HTTPS, and history lives in this browser only.
